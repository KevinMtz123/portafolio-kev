# Portafolio — Kevin Martínez

Landing page personal. HTML, CSS y JS puro (sin frameworks), con
componentes reutilizables en `script.js` (ver `REPOS`, `STACK_GROUPS`
y `FACTS` para editar el contenido).

## Estructura

- `index.html` — estructura de la página
- `styles.css` — estilos
- `script.js` — datos + render de componentes + interacciones

## Despliegue

Se despliega automáticamente a GitHub Pages en cada push a `main`
vía `.github/workflows/deploy.yml`.
